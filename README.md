# StarBot

StarBot — это Telegram-бот для покупки и отправки «звёзд» через Fragment. Это одновременно и любительский проект, и работающий сервис, предназначенный для экспериментов с ботами, микротранзакциями и криптовалютными платежами.

Бот написан на asyncio и использует SQLite через SQLAlchemy ORM (sqlite+aiosqlite) для хранения информации о клиентах и их заказах. Покупки звёзд обрабатываются через неофициальный Fragment API с использованием aiohttp. Платежи можно совершать в криптовалюте через Crypto Cloud.

## ⚙️ Установка и запуск (для разработчиков)
```bash
# Клонировать репозиторий
git clone https://github.com/Dinar6767/starseller-bot.git
cd starseller-bot

# Установить зависимости
pip install -r requirements.txt

# Запустить бота локально
python bot.py

Python (asyncio)

API Telegram-бота

📖 Использование
Запустите бота в Telegram командой /start.

Выберите действие в меню:

Кнопка	Описание
Купить звезды ⭐	Выберите количество звезд и введите имя пользователя получателя
Цена 💲	Текущая цена звезды в рублях
Поддержка	Свяжитесь с администратором
Как это работает 🛠️	Пошаговая инструкция по покупке
Назад 🔙	Возврат к предыдущему меню
Политика конфиденциальности	Ознакомьтесь с правилами конфиденциальности
💳 Способы оплаты
RUB (рубль)

USDT (криптовалюта)

Подтвердите платеж в боте. Администратор проверит его вручную. Звезды зачисляются получателю после проверки. ✅

💡 Как это работает
Выбрать звезды — выберите количество звезд для покупки ✨

Получатель — введите имя пользователя Telegram получателя

Оплата — выберите способ оплаты 💰

Подтверждение — подтвердите платеж в боте; администратор проверит транзакцию

Зачисление — после проверки звезды мгновенно зачисляются на счет получателя ✅
